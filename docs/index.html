Install in seconds

Pre-built static binaries — download, make executable, run.

ARM64 Linux (aarch64) — Required

wget https://github.com/addoransford020-cmd/notecli/releases/latest/download/notecli-aarch64-unknown-linux-musl chmod +x notecli-aarch64-unknown-linux-musl sudo mv notecli-aarch64-unknown-linux-musl /usr/local/bin/notecli notecli --version

x86_64 Linux — Bonus

wget https://github.com/addoransford020-cmd/notecli/releases/latest/download/notecli-x86_64-unknown-linux-musl chmod +x notecli-x86_64-unknown-linux-musl sudo mv notecli-x86_64-unknown-linux-musl /usr/local/bin/notecli notecli --version
