Install in seconds

Pre-built static binaries — download, extract and run.

ARM64 Linux — aarch64 (Required)
wget https://github.com/addoransford020-cmd/notecli/releases/download/v0.3.0/aarch64-unknown-linux-musl.tar.gz tar -xzvf aarch64-unknown-linux-musl.tar.gz sudo mv notecli /usr/local/bin/notecli notecli --version
Verify static linking
file /usr/local/bin/notecli # Output confirms: # notecli: ELF 64-bit LSB executable, ARM aarch64, statically linked
x86_64 Linux (Bonus)
wget https://github.com/addoransford020-cmd/notecli/releases/download/v0.3.0/x86_64-unknown-linux-musl.tar.gz tar -xzvf x86_64-unknown-linux-musl.tar.gz sudo mv notecli /usr/local/bin/notecli notecli --version
ARMv7 Linux (Bonus)
wget https://github.com/addoransford020-cmd/notecli/releases/download/v0.3.0/armv7-unknown-linux-musleabihf.tar.gz tar -xzvf armv7-unknown-linux-musleabihf.tar.gz sudo mv notecli /usr/local/bin/notecli notecli --version
